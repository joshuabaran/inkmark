`spec.json` holds the examples from the GitHub Flavored Markdown spec
(https://github.com/github/cmark-gfm/blob/master/test/spec.txt), by John
MacFarlane and GitHub, licensed CC-BY-SA 4.0
(https://creativecommons.org/licenses/by-sa/4.0/). Converted to JSON (one
object per example, `→` turned back into tabs, `extension` naming the GFM
extension an example belongs to); otherwise unmodified.
